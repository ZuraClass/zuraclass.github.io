Atur produk yang tampil di halaman Product.

  1. Di GitHub buka Settings → Developer settings → Personal access tokens → Fine-grained tokens, lalu Generate new token.
  2. Repository access: Only select repositories → pilih repo website ini.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Salin token, tempel di bawah. Token hanya disimpan di browser ini.

Halaman ini hanya bisa menyimpan perubahan kalau token valid. Data produk sendiri memang publik (tampil di /products), jadi yang dilindungi adalah izin menulis, bukan isi katalog.
